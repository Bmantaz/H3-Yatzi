# Yatzi.Core

Spillogik uden afhængigheder til web eller hardware – nem at teste (DoD 6).

Forslag til hvad der hører hjemme her:

- Terninger og kast (op til 3 slag pr. tur)
- Hold/slip terninger
- Pointtavlen: de 15 felter + bonus
- Ture og spillere (1–6)
- Hvornår spillet slutter, og hvem der vinder

Se reglerne i [docs/GDD.md](../../docs/GDD.md).
